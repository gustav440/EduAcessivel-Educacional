O que é programação?

Entenda o que significa programar e como os computadores seguem nossas instruções.

O que significa programar?

Programar é criar instruções para que um computador consiga realizar determinadas tarefas.

Essas instruções são escritas utilizando linguagens de programação, como JavaScript, Python e Java.

💡
Pense de forma simples:

Programar é como ensinar uma pessoa a realizar uma tarefa seguindo uma sequência de passos.

Um exemplo do dia a dia

Imagine que queremos ensinar alguém a fazer um sanduíche.

  1. Pegar o pão.
  2. Colocar o recheio.
  3. Fechar o sanduíche.
  4. Servir.

Um programa funciona de maneira parecida. O computador recebe uma sequência de instruções e executa cada uma delas.

Nosso primeiro exemplo

Em JavaScript podemos mostrar uma mensagem na tela utilizando:

JavaScript 
console.log("Olá, mundo!");

Esse comando faz o computador exibir a mensagem "Olá, mundo!" no console.

📚

O que aprendemos?

  • Programar é criar instruções.
  • Computadores seguem essas instruções.
  • Existem diferentes linguagens de programação.
  • JavaScript é uma das linguagens utilizadas para desenvolver sistemas.
